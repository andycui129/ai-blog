Step 5：理解ComfyUI的节点系统

ComfyUI的界面看起来像一张"电路图"——每个方框是一个节点，连线代表数据流向。一个基本的文生图工作流需要以下6个核心节点：

  1. Load Diffusion Model — 加载FLUX.2模型检查点
  2. CLIP Text Encode (Flux) — 将你的文字提示词编码为模型可理解的向量
  3. Empty Latent Image — 设置画布尺寸（宽×高）
  4. KSampler — 执行去噪采样，控制步数和CFG
  5. VAE Decode — 将潜空间图像解码为可视PNG
  6. Save Image — 保存到本地

连线顺序如下：

  • 模型加载器 → KSampler（提供模型权重）
  • 文本编码器 → KSampler（提供提示词条件）
  • Latent Image → KSampler（提供初始噪声画布）
  • KSampler → VAE Decode → Save Image
⚠️ FLUX.2关键差异：与Stable Diffusion不同，FLUX.2 不使用负面提示词（Negative Prompt），且CFG值（引导强度）必须严格控制。蒸馏版Klein 4B的CFG设1.0-1.5即可，设高了反而会炸图。

FLUX.2最惊艳的功能之一是多参考图模式——你可以上传1-6张参考图，让模型在新图像中保持一致的风格或人物特征。传统SD需要花几小时训练LoRA才能做到的事，FLUX.2只需拖入几张图即可。

在ComfyUI中，加载FLUX.2多参考图工作流模板后，将参考图节点全部取消旁路（Bypass取消勾选），每个节点各载入一张参考图，就能生成风格高度统一的一系列图像。对于设计品牌视觉、游戏角色设计、电商产品图的场景，这个功能直接省掉了80%的后期调整时间。
